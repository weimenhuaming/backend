# 有关Etcd的容器的构建和启动记录
其实更为常用的一种方式是直接docker run去拉取etcd，只不过这样的镜像其实官方比较基础的镜像，有时候我们可能会对镜像做一些处理，好统一规范和要求。在初学阶段其实建议直接使用docker run命令直接拉取，除非你需要一些特殊的组件或者有特殊要求。

## 1.构建Docker镜像

在这个目录下我已经搭建好了一个轻量级的Etcd镜像的dockerfile，接下来就是第一步构建镜像

```bash
# 在 Dockerfile 所在目录执行
docker build -t my-etcd:v3.6.10 .
```

下载完成之后可以通过下面命令来验证是否构建成功，如果有名字为 my-etcd，则说明成功
```bash
docker images
```

## 2.挂载

挂载实际上就是为了保证容器内部的数据不丢失，如果你感觉无所谓，或者是测试，其实可以选择不挂载。  
在挂载之前，首先需要你在宿主机上创建一个你需要挂载的位置

## 3.运行容器并挂载目录

我这里的容器的启动是在windows系统上，所以我挂载的目录当然也是windows上。  
如果你需要在linux系统上，挂载的目录需要你自行更改一下

```bash
   docker run -d `
  --name my-etcd:v3.6.10 `
  -p 2379:2379 `
  -p 2380:2380 `
  -v D:\Docker\etcd3.6.10:/etcd-data `
  my-etcd:v3.6.10
```

可以通过下面命令查看我们的容器是否已经正常启动：

```bash
docker ps
```

## 4，验证是否挂载成

这个时候只需要我们进入宿主机的D:\Docker\etcd3.6.10目录下，查看是否有文件(member)，有则说明挂载成功了
